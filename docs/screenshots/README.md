# 画面例

このディレクトリのPNGは、Scannerの実際のfrontendをブラウザで撮影したものです。画像の合成やUIの描き直しは行っていません。

- `home-desktop.png`: PCのホーム。
- `ocr-desktop.png`: PCのOCR確認と、選択行に対応する原稿の強調。
- `ocr-mobile.png`: スマートフォン幅の同じOCR確認。

2026-11-14、v0.2.30相当のfrontend、Chromium155、1440×1000／390×844のviewportで撮影。loopbackの読み取り専用fixtureを使い、原稿・スキャナー名・認識結果は架空データです。私文書・認証情報・本番sessionは使用していません。OCR結果はモデル精度の実測値ではありません。プロジェクト独自のデモ素材としてApache-2.0で配布します。
