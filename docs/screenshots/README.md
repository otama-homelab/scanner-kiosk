# Screenshots

These PNGs are browser captures of the real Scanner Kiosk frontend. They are not generated mockups or edited interface illustrations.

- `home-desktop.png`: desktop home with acquisition choices.
- `ocr-desktop.png`: desktop OCR comparison with the selected line highlighted on the source.
- `ocr-mobile.png`: the same comparison at a mobile viewport width.

The English UI captures use a loopback, read-only synthetic fixture and the unchanged application frontend. The Japanese invoice demonstrates bilingual document content; scanner names and recognized results are demo data. No private document, credential, or production session is used. These screenshots do not measure model accuracy.

Captured on 2026-11-15 using the unchanged v0.2.32 frontend, Chromium 155, and 1440×1000 desktop / 390×844 mobile viewports (the mobile capture includes the full page). Exact image hashes are recorded with the release verification evidence. Original project demo assets are distributed under Apache-2.0.
