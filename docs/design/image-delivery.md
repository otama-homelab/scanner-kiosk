# Source image delivery

`GET /api/documents/{document_id}/pages/{page_id}/preview` serves a page's original PNG/JPEG in source orientation. The frontend applies the rotation from page metadata once. HEAD returns the authorized media type and length without a body. There is no caller-supplied filename or storage path. This endpoint ignores Range and serves a complete image. Current-export downloads use the separate route below.

The document repository joins page, document, owner and ready original artifact in one transaction while holding the enabled-principal guard. It rejects another document's page, a removed page, disabled principal, expired/deleting document, or unsupported media type. Paths, hashes and expiry are passed only to the internal adapter and are not JSON projections.

`artifactread` pins a private root with `os.Root`, permits only local normalized relative paths, rejects a non-regular final directory entry, and compares it with the opened descriptor using SameFile. Root confinement prevents outside traversal, including intermediate symlink escapes. Go Root.OpenFile follows confined symlinks despite an O_NOFOLLOW flag, so the explicit entry check matters; this is not a claim that all intermediate symlinks are forbidden. Descriptor checks enforce regular type, private permissions, exact size and configured job-byte limit. The opened file's full SHA-256 is checked before returning bytes. Reads honor cancellation and never exceed the authorized size. No output/work directory is created. Ready artifacts must remain immutable after publication; this does not sandbox a privileged process which can rewrite them.

After verification, HTTP repeats authorization before sending headers and before each 32 KiB write. Authorization checks the original admitting session as well as page membership or the current output reference, enabled owner and TTL. A watcher also checks every 100 ms while a write may be blocked, using a 500 ms probe context. Any error or revoked reference cancels the stream and advances the socket write deadline. A deadline at the earlier of document expiry, request deadline and configured transfer timeout prevents a blocked write from continuing beyond expiry. `SCANNER_TRANSFER_TIMEOUT_SECONDS` defaults to 300, accepts 1–900, and is API-only. The admission middleware uses this duration for GET/HEAD download and preview paths; ordinary API requests keep their 30-second context. The stream controller overrides the server's shorter default write deadline for these authorized transfers. Deadline support is required; unsupported response wrappers fail closed. Watcher shutdown is joined before the handler returns so no observer can alter a later response's deadline.

Cancellation aborts the HTTP stream; it cannot recall bytes already delivered or buffered by the network/proxy. The watcher interval and database/transport scheduling mean revocation is not an instantaneous physical cutoff. No database transaction is held while writing network bytes. After abort, the handler does not append JSON to an image. Responses include one Cache-Control: no-store directive, nosniff, no-referrer, Vary: Cookie, same-origin resource policy and inline content disposition. The application replaces SCS's additional cookie-cache directive with its stricter no-store policy.

Tests cover verified real PNG delivery over an actual Go HTTP listener, unchanged source orientation, HEAD, anonymous/cross-owner/cross-document denial, removed pages, corrupted bytes, private-root/path/descriptor checks, pinned-root replacement and bounded reads. Deterministic blocked-writer fixtures cover page deletion, guest end, original session revocation and expiry. These fixtures exercise deadline/cancellation logic; they are not saturated real-network or reverse-proxy acceptance. The compiled CLI also serves a synthetic real PNG and rejects anonymous/other-owner access. Scanner acquisition, thumbnail generation, actual browser/proxy/mobile behavior and deployment remain pending.

## Current-export downloads

`GET /api/documents/{document_id}/download` serves only the currently published output at the document's current revision. Its owner, artifact identity and expiry are resolved together. The route supports PDF/JPEG/PNG with fixed safe attachment names (`scan.pdf`, `scan.jpg`, `scan.png`). It exposes no user filename or filesystem path. A page edit invalidates the output pointer, denying new downloads and causing the shared stream watcher to abort an existing transfer.

GET accepts a single bytes Range: closed, open-ended or suffix. It bounds the requested interval to the trusted size, clamps an end beyond EOF, and emits 206 plus Content-Range/Content-Length. Multiple, malformed, overflowing or unsatisfiable ranges return an empty 416 with `Content-Range: bytes */size`. Every request repeats session/owner/retention checks. HEAD ignores Range and returns full metadata. Since no representation validator is advertised, If-Range causes a conservative full 200 response. Conditional 304 caching is not used. Accept-Ranges is bytes; multipart ranges are unsupported.

`artifactread.OpenRange` verifies the entire opened file before seeking to the authorized interval, and limits all subsequent reads to that interval. Corruption outside a requested range therefore still prevents delivery. Stream rechecks use the exact output reference, so replacement or invalidation aborts the previous transfer even when an old file remains on disk. The stream watcher, private root, deadline and no-store rules are shared with previews.

Tests cover full, suffix/open/closed/clamped ranges, malformed and out-of-bounds requests, If-Range fallback, HEAD, anonymous/other-owner ranges, and invalidation after a real page edit. A blocked-writer fixture proves invalidation stops a partial transfer. API tests use a labeled PDF transport fixture; the compiled CLI uses a generated blank PDF, independently checked with pikepdf as one A4 page without repair warnings. These tests do not prove browser download-manager resume, large-file throughput or live proxy timeout behavior.
