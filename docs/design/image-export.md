# Single-image photo export

`internal/imageexport` implements bounded JPEG/PNG output independently of PDF assembly and OCR providers. It fully validates the original bitmap, expected dimensions and color using the capture validator. Matching format with zero rotation preserves the exact original encoded bytes. Other requests decode once, rotate clockwise by 90/180/270 degrees and encode as explicit 8-bit grayscale/RGB. JPEG encoding uses the worker's current quality policy; PNG preserves decoded pixels, including when the source was JPEG (it cannot restore detail lost in JPEG compression).

Input/output bytes and pixel counts are bounded, writes honor context cancellation and rotation checks cancellation each source row. A finished encoded image is validated before scope publication. The engine runs in the resource-limited worker. Image dimensions are retained or swapped for quarter turns; this does not prove optical DPI or preserve ancillary metadata during re-encoding. Capture DPI remains in the immutable page snapshot; real capture/DPI and metadata acceptance remain pending.

`renderjob.Prepare` selects PDF or single-image rendering from the immutable settings. JPEG/PNG exports require exactly one source page, use the same DB-derived allowlist, deadline, reservation, scope seal, conditional publication and uncertainty cleanup as PDFs, and advertise the matching image media type. OCR-enabled jobs remain explicitly unsupported by this coordinator. Existing photo admission already enforces the one-page purpose constraint.

Tests check exact unmodified JPEG/PNG streams, independent result bytes, all three clockwise rotations, lossless pixel locations, grayscale/RGB conversion, 8-bit JPEG-to-PNG pixels, encoded/pixel limits and cancellation. Worker runtime tests admit photo jobs through the real DB service and verify both requested formats, rotated dimensions and unchanged originals. The compiled CLI proof additionally exercises JPEG/PNG jobs and independently inspects output using Pillow. No physical photo scan, browser/download flow, metadata/DPI benchmark or production resource acceptance is established here.
